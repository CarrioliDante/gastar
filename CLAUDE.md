# Gastar Context

Use this file only for repo-specific context. Do not restate generic engineering guidance already covered globally.

- Gastar is a minimalist personal finance operating system, not a fintech dashboard.
- UI should feel calm, monochromatic, editorial, spacious, and low-anxiety.
- Prefer glanceable summaries, strong typography, and subtle motion.
- Avoid colorful analytics, noisy cards, heavy shadows, and gradient-heavy finance UI.
- Web: Next.js 16 + Supabase + Prisma. Mobile: Expo + React Native. Shared contracts live in `packages/shared`.
