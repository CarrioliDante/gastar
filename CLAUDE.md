# GLOBAL PROJECT INSTRUCTIONS

# Product Identity

This project is NOT:

- a fintech dashboard
- a banking application
- a crypto product
- an accounting tool
- an enterprise finance system

This project IS:
a minimalist personal finance operating system.

The experience should feel:

- calm
- premium
- elegant
- Japanese-inspired
- monochromatic
- editorial
- emotionally quiet

The interface must communicate:

- clarity
- focus
- control
- simplicity
- reduced financial anxiety

---

# UX Philosophy

Whitespace is a feature.

The UI should feel:

- breathable
- lightweight
- intentional
- silent

Prioritize:

- typography hierarchy
- spacing rhythm
- glanceable information
- smooth interactions
- visual calmness

Avoid:

- clutter
- noisy dashboards
- excessive cards
- aggressive shadows
- gradients
- enterprise patterns
- fintech aesthetics
- colorful analytics
